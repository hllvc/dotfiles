# functions

Scripts sourced as shell functions so they can change the working directory. Both source the shared helpers in [`../lib/worktree.sh`](../lib/worktree.sh).

[Back to scripts](../)

## Scripts

| Script | Description |
|--------|-------------|
| `gbare.sh` | Clones a GitHub repo as a bare repository with worktree structure and creates the initial default branch worktree |
| `sw.sh` | fzf branch switcher for bare+worktree repos. One line per branch in fixed columns: the name colored by state against `origin/<default>` (dim = merged, incl. squash and rebase merges; cyan = new, no commits of its own yet), where (`worktree`/`local`/`remote`), status (sync against the branch's own remote: `⇡⇣`, `unpushed`, `gone`, blank when in sync, an `origin/main` upstream is ignored; then powerlevel10k-style `~` conflicted, `+` staged, `!` modified, `?` untracked counts), age and subject, recently visited branches first (marked `·`), then newest commit first. Remote-only branches show when yours or active within `sw.remoteAge` days (default 14); `-r`/`ctrl-a` shows all. Preview shows the state, worktree status, carry health and the branch's own commits. State is cached in `.bare/sw.state` and `.bare/sw.patchids`. `sw [branch]` switches (nested path preserved, unknown name offers to create), `sw -` goes back, `sw -c [name [base]]` creates (offers to move uncommitted changes along, runs `sw.postCreate`, `--no-rebase` or `sw.rebase=false` skips the rebase), `sw -d` multi-select delete showing each branch's state, warning about unmerged commits on no remote, and asking a second time before discarding uncommitted changes, `sw st` shows every worktree, `-a` fetches first, `-l` lists, `-L` hides remote-only refs, `-r` shows them all, `-h` help. Picker keys: `ctrl-x` delete, `ctrl-o` create from highlighted, `ctrl-r` fetch + reload, `ctrl-a` all remotes, `alt-m`/`alt-g`/`alt-n` show only merged/gone/new branches (named in the prompt, kept across `ctrl-r`), `alt-0` all, `ctrl-/` swaps the preview for a key and legend cheat sheet. Key bindings from `FZF_DEFAULT_OPTS` are passed again after sw's own in every picker, so personal mappings always win, and the cheat sheet lists them. The header is a single dim line (branch, repo, hidden remote count). `sw carry` manages gitignored local files (tfvars, .env) carried into every worktree: symlinks into `<repo>/.local/` or per-branch copies, detach/forget (`ctrl-s`/`ctrl-o`/`ctrl-t`/`ctrl-x`), `carry ls|apply|diff|reset|edit`, remembered in `.bare/config`. Picker scans every worktree and shows which branches hold each file. `sw.remote` overrides `origin` |
